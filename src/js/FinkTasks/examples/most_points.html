Find objects with the most points

This page runs the original most_points.py task on the local example server. The fields correspond to its CLI arguments, with the same defaults. Generated JSON and optional PNG files appear as downloads.

Start python3 examples/serve.py from src/js/FinkTasks. The server binds to 127.0.0.1, keeps artifacts only while it runs, and stores --output-dir inside a temporary per-run directory. Light-curve PNGs need Matplotlib in the server's Python environment. Remote HTTP Elasticsearch access requires explicit consent.

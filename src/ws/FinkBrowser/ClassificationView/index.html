Help

Application shows classification-based neigborhood (i.e. other objects with similar classification) for any object of ZTF or LSST. User can choose:

  • Object ID of requested object from either ZTF (starts with ZTF) or LSST (numeric). The survey is selected automatically.
  • Classifier used to classify objects.
    • FINK is based on the FINK classification (ZTF and LSST).
    • XMATCH is based on other classifications acquired via FINK (ZTF only).
    • FEATURES uses PCA/clustering of alert properties, with 2025/13-50 and 2024/13-60 flavors (ZTF only).
    • TAG uses user-supplied selections (ZTF and LSST).
  • Re-Classifier can re-interpred classification by another Classifier.
    • none doesn't re-interpret.
  • Metric to calculate distances between objects in the space of classifications.
  • nmax - the maximal number of closest objects to show. If less than 1, the number of objects to show is calculated via differences in distances between subsequent objects (smaller numbers is less selective). 0 gives all close objects.
Double-click on an object (represented by blue star) triggers the search centered on that object. Objects pop-up shows classification details and allows to navigate to Fink Portal of concerned object.shown A list of those objects is shown too, with the same information (distances and classifications). If data loading fails, the demo data are shown.

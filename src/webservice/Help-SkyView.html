SkyView

Select an object vertex in the graph and choose SkyView in Selection actions. This plots every object currently in the graph (including objects inside collapsed clusters), not just the selected one. Alternatively, open an object table and click Sky View to plot the objects in its rows. Both actions look up positions in Fink Elasticsearch and use the same map; ZTF objects are orange and LSST objects blue. Small object IDs appear beside each point, and hovering over a point shows its full ID in a light popup. The map and its zoom and download buttons fit the SkyView pane. Open Map settings for the other sky controls, or expand Plotted object coordinates for the RA/Dec list.

Objects without coordinates are counted but not plotted. Solar System objects can have several positions, so they may appear more than once. The table's existing Sky coordinate route remains available for non-object rows containing ra and dec.

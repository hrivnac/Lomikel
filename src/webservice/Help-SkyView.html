SkyView

Select an object vertex in the graph and choose SkyView in Selection actions. This plots every object currently in the graph (including objects inside collapsed clusters), not just the selected one. Positions are looked up in Fink Elasticsearch; ZTF and LSST objects can appear together.

Objects without coordinates are counted but not plotted. Solar System objects can have several positions, so they may appear more than once. The existing Sky control in a node's table remains available for plotting table rows that contain ra and dec.

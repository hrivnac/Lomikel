Connection & actions

Choose a graph server, then select an initial graph and press Search. To run a Gremlin command instead, enter it and press Execute.

The Add results to current graph option keeps the current graph when new results are loaded. Without it, a new search replaces the displayed graph.

After selecting a node or edge in the graph, available actions appear in Selection actions. Some links open an external service in a new window; embedding can be restricted by that service.

Tag (object vertices) registers the object in the TAG collection GraphBrowser of its survey's graph database (LSST: CC, ZTF: IJCLab) after a confirmation. The write is made by the Graph Browser server with the writable CCRW.properties / IJCLabRW.properties graph configurations packaged inside the WAR (override with files using -Dfink.tag.janus.LSST=… / -Dfink.tag.janus.ZTF=…); the read-only graph servers can take a few minutes to show the new tag.

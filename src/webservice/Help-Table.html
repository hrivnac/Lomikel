Table

Tabular views of graph data appear here when an action produces a table. Choose a graph element and use one of its available actions to populate this tab.

Where the table offers column controls, select fields for plotting or inspection, then use the table's own action buttons. For graph tables with a time column, Evolution Plot charts every selected x and y field as a separate series against time; z controls marker size, s color, and k point details. The table and its available controls depend on the selected data.

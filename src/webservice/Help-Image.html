Image

Select an object vertex in GraphView and choose Cutouts. This tab shows a row for each distinct object currently in the graph, including clustered objects, with its latest Science, Template, and Difference cutout from Fink Portal. Up to 30 objects can be displayed at once. An unavailable stamp or source is marked in its cell.

The initial placeholder remains until an action loads an image. ZTF uses the object's most recent alert; LSST DIA objects use the latest diaSource returned by Fink's sources API. LSST Solar System objects are reverse-resolved to a designation, then use the source with the greatest observation MJD from Fink's SSO API. Both LSST routes request stamps by diaSourceId.

Graph controls

Click a node or edge to inspect its properties and available actions. Double-click a node to expand it; choose Children, Parents, or both to control the direction. Replace current graph on expansion removes the previously displayed graph.

Explore and view

  • Result limit appends a Gremlin traversal such as limit(10) to graph requests.
  • Live physics moves nodes into place. Hierarchical, Vertical, and Sort by hub size adjust the graph layout.
  • Filter labels shows nodes whose labels contain the entered text; press Apply to update the view.

Whole graph

Use Group nodes or Cluster hubs to simplify a crowded view. Open clusters expands collapsed clusters; Show all edges reveals connections between visible nodes. Automatic clustering and stabilization can be toggled in this section.

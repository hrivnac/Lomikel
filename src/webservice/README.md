# FinkBrowser workspace preview

This first iteration changes only the *shell*, not the contents or server-side logic of the panels. The existing root `index.jsp` remains the default welcome page. The new shell is available at `/FinkBrowser/webservice/index.jsp` after `ant war`; use `?profile=null` to inspect it without an automatic graph query, or the same configured profile query string used by the existing UI. Do not run a configured profile against production merely to test layout.

Build from `ant/` with `ant war` using the usual local Ant properties and dependencies. `ant start-FinkBrowser` serves the resulting `lib/FinkBrowser.war` at the configured port, but starts a service that may connect to the configured backends. `ant war` does not deploy it; neither the `deploy*` targets nor a remote server are needed to preview the shell. For an isolated local test, run Jetty Runner bound to `127.0.0.1` on a spare port using the built WAR.

The new JSP is packaged under `webservice/`, but its `<base>` points at the WAR root so existing JS, CSS, detail fragments and relative action URLs remain unchanged. It statically includes the Fink `Init.jsp`. Panels 01 and 02 now load preview-only `webservice/TopMini.jsp` and `webservice/Top.jsp`: they keep the original Reset, server/graph/command controls, action IDs, Gremlin callbacks and dynamic `#commands` target. Their logos, version/build metadata and initial command are substituted by the WAR build just as in the legacy root fragments; the legacy pages remain unchanged. Other panels still load their root fragments. The w2ui layout names (`layout`, `layoutLeft`, `layoutMain`), tab IDs, `loadPane` targets and `feedback`/`commands` callbacks remain stable for current graph actions and nested frames. Drag a divider to resize; **Reset layout** restores only panel sizes, while **Reset workspace** reloads application panels and restores the preview connection form.

GraphView.jsp still computes its initial `#vis` height with the legacy viewport expression. This shell supplies its expected global `height` and lets the graph pane own the displayed height with flex CSS; a resize observer updates `visheight` and redraws an existing network without changing zoom. The initial load, automatic profile bootstrapping and all backend-driven actions remain owned by the original JSPs and scripts. In particular, this preview does not claim to repair missing backend data or detail-pane behavior.

Offline check: `python3 -m unittest src.test.python.test_webservice_shell -v` from the repository root (the archive check skips unless `lib/FinkBrowser.war` exists). The initial browser smoke test should use `profile=null`, then inspect all five panels, switch tabs, drag both column and row dividers, click **Reset layout**, test the original **Reset**, and only then test a configured profile in an appropriate isolated environment.
